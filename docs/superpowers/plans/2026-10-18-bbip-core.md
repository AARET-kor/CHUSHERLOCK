# BBIP Core Implementation Plan (Plan 1 of 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 홈(`/`)을 BBIP 콘솔로 바꾼다. 한 줄 케이스 입력 → 칩 + 🚨플래그 → ⚡핵심 브리핑 → 맞춤 질문·섹션 9개·직접 질문으로 파고들기 → 히스토리 → 노트로 저장(draft).

**Architecture:** 순수 로직은 `lib/bbip/*`에 둔다(types, sections, flags, evidence, followups, parse, prompts, context, generate, runTurn). 영속화는 `lib/services/bbipService.ts`(Drizzle, 새 테이블 2개)가 맡는다. API는 `app/api/bbip/*`이고, turn 스트림은 NDJSON이다. UI는 `components/bbip/*` 클라이언트 컴포넌트이며, 상태는 순수 reducer(`lib/bbip/consoleState.ts`)로 관리한다. 모든 AI 호출에는 `CODEX_AI_MODE=fake` 경로가 있다.

**Tech Stack:** Next.js 15 App Router, TypeScript, Drizzle + better-sqlite3, Zod, `@anthropic-ai/sdk` 0.110(beta messages stream, `output_config.effort`, `fallbacks`), Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-18-bbip-design.md`

**이 계획의 범위 밖 (후속 계획):**
- Plan 2 — 🔬 문헌 보강(PubMed, 웹검색, `literature_cache`) + 근거 배지 확장(📖 교과서 *책명* p.x, 🔬 `[P#]`, 🌐 `[W#]`)
- Plan 3 — 🧭 해부 지도(아틀라스, FaceMap, 단면도, 위험 구조물 표, 내 자료 그림)

**스펙 대비 단순화 (의도적):**
- 노트 승격 시 카테고리 제안은 Haiku 호출 대신 **세션에서 가장 관련도 높은 노트의 카테고리**로 결정론적으로 정한다. 다이얼로그에서 수정할 수 있다.
- 칩을 수정해 새 세션을 만들 때는 **규칙 기반 플래그만** 다시 계산한다. 파서를 다시 부르지 않는다.
- 카드 **일부를 드래그로 골라 저장**하는 UI는 넣지 않는다. API(`selection` 필드)는 받아 두지만, 렌더된 배지 텍스트를 마커로 되돌리는 문제가 있어 v1 UI는 카드 전체만 저장한다.
- 섹션 모델 중 Sonnet 호출에는 `fallbacks`를 넣지 않는다. SDK 0.110 타입에는 배열 형태만 있는데, 스킬 문서상 Sonnet 5.5는 `"default"` 형태만 받기 때문이다. 거부(refusal)는 카드 안의 안내 문구로 처리한다.

// Domain vocabulary for BBIP — the aesthetic-GP chairside assistant.
// Kept separate from the DB schema so storage can change without reshaping
// the domain (same convention as lib/codex/types.ts).

export type FlagLevel = "contraindication" | "caution";

export interface Flag {
  level: FlagLevel;
  text: string;
  /** "rule" = deterministic keyword table (lib/bbip/flags.ts), "model" = parser. */
  source: "rule" | "model";
}

/** Structured chips parsed from the one-line case memo. The raw memo itself
 * is never persisted — only these chips. */
export interface ParsedCase {
  patient: string[];
  conditions: string[];
  meds: string[];
  procedures: string[];
}

export type SectionKey =
  | "cautions"
  | "adverse"
  | "ddx"
  | "tips"
  | "schedule"
  | "homecare"
  | "marketing"
  | "alternatives"
  | "notes";

export type TurnKind = "brief" | "section" | "followup" | "custom";
export type TurnStatus = "streaming" | "done" | "failed";

export interface TurnRequest {
  kind: TurnKind;
  sectionKey?: SectionKey;
  question?: string;
}

export interface BbipSession {
  id: string;
  chips: ParsedCase;
  flags: Flag[];
  /** Notes retrieved once at session creation, in relevance order. Index+1
   * is the citation number [n] for every turn of the session. */
  sourceNoteIds: string[];
  promptVersion: string;
  createdAt: string;
}

export interface BbipTurn {
  id: string;
  sessionId: string;
  kind: TurnKind;
  sectionKey?: SectionKey;
  question?: string;
  output: string;
  followups: string[];
  model: string;
  status: TurnStatus;
  error?: string;
  promotedEntryId?: string;
  createdAt: string;
}

/** A citable note as the client sees it: [n] → /entries/id. */
export interface NoteRef {
  n: number;
  id: string;
  title: string;
  categoryLabel: string;
}

export interface SessionView {
  session: BbipSession;
  turns: BbipTurn[];
  notes: NoteRef[];
}

export type StreamEvent =
  | { type: "start"; turnId: string }
  | { type: "delta"; text: string }
  | { type: "followups"; items: string[] }
  | { type: "done"; turnId: string }
  | { type: "error"; message: string };

export const BBIP_PROMPT_VERSION = "bbip-v1";
```

const BY_KEY = new Map(SECTIONS.map((section) => [section.key, section]));

export function getSection(key: SectionKey): SectionDef {
  const section = BY_KEY.get(key);
  if (!section) throw new Error(`Unknown BBIP section: ${key}`);
  return section;
}

export function isSectionKey(value: string): value is SectionKey {
  return BY_KEY.has(value as SectionKey);
}

/** Card heading for a turn — shared by the UI, prompts, and note titles. */
export function turnTitle(turn: Pick<TurnRequest, "kind" | "sectionKey" | "question">): string {
  if (turn.kind === "brief") return "⚡ 핵심 브리핑";
  if (turn.kind === "section" && turn.sectionKey) {
    const section = getSection(turn.sectionKey);
    return `${section.emoji} ${section.label}`;
  }
  return `💬 ${turn.question ?? "질문"}`;
}

export function ruleFlags(chips: ParsedCase): Flag[] {
  const haystack = [...chips.patient, ...chips.conditions, ...chips.meds, ...chips.procedures]
    .join(" ")
    .toLowerCase();
  return RULES.filter((rule) => rule.keywords.some((k) => haystack.includes(k.toLowerCase()))).map(
    (rule) => ({ level: rule.level, text: rule.text, source: "rule" as const })
  );

/** Rule flags win ties (same text); contraindications sort first. */
export function mergeFlags(rule: Flag[], model: Flag[]): Flag[] {
  const seen = new Set<string>();
  const merged: Flag[] = [];
  for (const flag of [...rule, ...model]) {
    const key = flag.text.trim();
    if (!key || seen.has(key)) continue;
    seen.add(key);
    merged.push({ ...flag, text: key });
  }
  const rank = (f: Flag) => (f.level === "contraindication" ? 0 : 1);
  return merged
    .map((flag, index) => ({ flag, index }))
    .sort((a, b) => rank(a.flag) - rank(b.flag) || a.index - b.index)
    .map(({ flag }) => flag);
}

import { marked } from "marked";
import type { NoteRef } from "./types";

// The model ends claims with evidence markers: [n] for the doctor's own note
// n, [AI] for unverified model knowledge. Markers are swapped for Unicode
// private-use sentinels before Markdown parsing (so marked never mistakes
// them for link syntax), then replaced with badge HTML afterwards.

const MARKER = /\[(\d{1,2}|AI)\]/g;
const OPEN = "";
const CLOSE = "";
const SENTINEL = new RegExp(`${OPEN}(\\d{1,2}|AI)${CLOSE}`, "g");

function escapeAttr(value: string): string {
  return value.replace(/&/g, "&amp;").replace(/"/g, "&quot;").replace(/</g, "&lt;");
}

export function renderEvidenceHtml(markdown: string, notes: NoteRef[]): string {
  const byN = new Map(notes.map((note) => [note.n, note]));
  const withSentinels = markdown.replace(MARKER, (_match, token: string) => `${OPEN}${token}${CLOSE}`);
  // Same escaping rule as components/MarkdownContent: neutralize raw HTML,
  // keep ">" so blockquotes still parse.
  const escaped = withSentinels.replace(/&/g, "&amp;").replace(/</g, "&lt;");
  const html = marked.parse(escaped, { breaks: true, async: false }) as string;
  return html.replace(SENTINEL, (_match, token: string) => {
    if (token === "AI") {
      return '<span class="ev ev-ai" title="검증되지 않은 AI 보충">🤖AI</span>';
    }
    const note = byN.get(Number(token));
    if (!note) return `[${token}]`;
    return `<a class="ev ev-note" href="/entries/${note.id}" title="${escapeAttr(note.title)}">📚${note.n}</a>`;
  });
}

export function citedNoteNumbers(markdown: string): number[] {
  const numbers = new Set<number>();
  for (const match of markdown.matchAll(MARKER)) {
    if (match[1] !== "AI") numbers.add(Number(match[1]));
  }
  return Array.from(numbers).sort((a, b) => a - b);
}

/** Plain note body for promotion: note markers become relations (dropped
 * from text), AI markers stay visible as "(AI 보충)". */
export function toPlainNoteText(markdown: string): string {
  return markdown
    .replace(/\[AI\]/g, " (AI 보충)")
    .replace(/\s*\[(\d{1,2})\]/g, "")
    .replace(/ {2,}/g, " ")
    .replace(/[ \t]+\n/g, "\n")
    .trim();
}

// The brief ends with <followups>["…","…"]</followups>. The extractor lets
// the visible part stream through immediately while withholding the tag —
// including a partial "<follo" at a chunk boundary — so it never flashes on
// screen.

const OPEN = "<followups>";
const CLOSE = "</followups>";
const MAX_ITEMS = 4;
const MAX_CHARS = 80;

export function parseFollowups(body: string): string[] {
  let items: string[] = [];
  try {
    const parsed: unknown = JSON.parse(body);
    if (Array.isArray(parsed)) items = parsed.filter((x): x is string => typeof x === "string");
  } catch {
    items = body.split("\n").map((line) => line.replace(/^\s*(?:[-*]|\d+[.)])\s*/, ""));
  }
  return items
    .map((item) => item.trim().slice(0, MAX_CHARS))
    .filter(Boolean)
    .slice(0, MAX_ITEMS);
}

export class FollowupExtractor {
  private pending = "";
  private captured: string | null = null;

  /** Feed a model chunk; returns the text that is safe to show now. */
  push(chunk: string): string {
    if (this.captured !== null) {
      this.captured += chunk;
      return "";
    }
    this.pending += chunk;
    const index = this.pending.indexOf(OPEN);
    if (index >= 0) {
      const visible = this.pending.slice(0, index);
      this.captured = this.pending.slice(index + OPEN.length);
      this.pending = "";
      return visible;
    }
    let hold = 0;
    for (let k = Math.min(OPEN.length - 1, this.pending.length); k > 0; k--) {
      if (OPEN.startsWith(this.pending.slice(-k))) {
        hold = k;
        break;
      }
    }
    const visible = this.pending.slice(0, this.pending.length - hold);
    this.pending = this.pending.slice(this.pending.length - hold);
    return visible;
  }

  finish(): { tail: string; followups: string[] } {
    if (this.captured === null) {
      const tail = this.pending;
      this.pending = "";
      return { tail, followups: [] };
    }
    const body = this.captured.split(CLOSE)[0] ?? "";
    return { tail: "", followups: parseFollowups(body.trim()) };
  }
}

import { db } from "../db/client";
import { bbipSessions, bbipTurns } from "../db/schema";
import {
  BBIP_PROMPT_VERSION,
  type BbipSession,
  type BbipTurn,
  type Flag,
  type ParsedCase,
  type SectionKey,
  type TurnKind,
  type TurnRequest,

// better-sqlite3 is synchronous; these functions are too.

type SessionRow = typeof bbipSessions.$inferSelect;
type TurnRow = typeof bbipTurns.$inferSelect;

function nowIso(): string {
  return new Date().toISOString();
}

function toSession(row: SessionRow): BbipSession {
  return {
    id: row.id,
    chips: row.chips,
    flags: row.flags,
    sourceNoteIds: row.sourceNoteIds,
    promptVersion: row.promptVersion,
    createdAt: row.createdAt,
  };
}

function toTurn(row: TurnRow): BbipTurn {
  return {
    id: row.id,
    sessionId: row.sessionId,
    kind: row.kind as TurnKind,
    sectionKey: (row.sectionKey ?? undefined) as SectionKey | undefined,
    question: row.question ?? undefined,
    output: row.output,
    followups: row.followups,
    model: row.model,
    status: row.status as TurnStatus,
    error: row.error ?? undefined,
    promotedEntryId: row.promotedEntryId ?? undefined,
    createdAt: row.createdAt,
  };
}

export function createSession(input: {
  chips: ParsedCase;
  flags: Flag[];
  sourceNoteIds: string[];
}): BbipSession {
  const row: SessionRow = {
    id: randomUUID(),
    chips: input.chips,
    flags: input.flags,
    sourceNoteIds: input.sourceNoteIds,
    promptVersion: BBIP_PROMPT_VERSION,
    createdAt: nowIso(),
  };
  db.insert(bbipSessions).values(row).run();
  return toSession(row);
}

export function getSession(id: string): BbipSession | null {
  const row = db.select().from(bbipSessions).where(eq(bbipSessions.id, id)).get();
  return row ? toSession(row) : null;
}

export function listSessions(limit = 30): BbipSession[] {
  return db
    .select()
    .from(bbipSessions)
    .orderBy(desc(bbipSessions.createdAt))
    .limit(limit)
    .all()
    .map(toSession);
}

export function startTurn(sessionId: string, request: TurnRequest, model: string): BbipTurn {
  const row: TurnRow = {
    id: randomUUID(),
    sessionId,
    kind: request.kind,
    sectionKey: request.sectionKey ?? null,
    question: request.question ?? null,
    output: "",
    followups: [],
    model,
    status: "streaming",
    error: null,
    promotedEntryId: null,
    createdAt: nowIso(),
  };
  db.insert(bbipTurns).values(row).run();
  return toTurn(row);
}

export function finishTurn(turnId: string, output: string, followups: string[]): void {
  db.update(bbipTurns)
    .set({ output, followups, status: "done", error: null })
    .where(eq(bbipTurns.id, turnId))
    .run();
}

export function failTurn(turnId: string, output: string, error: string): void {
  db.update(bbipTurns)
    .set({ output, status: "failed", error })
    .where(eq(bbipTurns.id, turnId))
    .run();
}

export function getTurn(id: string): BbipTurn | null {
  const row = db.select().from(bbipTurns).where(eq(bbipTurns.id, id)).get();
  return row ? toTurn(row) : null;
}

/** Turns in creation order (rowid breaks same-millisecond ties). */
export function listTurns(sessionId: string): BbipTurn[] {
  return db
    .select()
    .from(bbipTurns)
    .where(eq(bbipTurns.sessionId, sessionId))
    .orderBy(asc(bbipTurns.createdAt), asc(sql`rowid`))
    .all()
    .map(toTurn);
}

export function markPromoted(turnId: string, entryId: string): void {
  db.update(bbipTurns).set({ promotedEntryId: entryId }).where(eq(bbipTurns.id, turnId)).run();
}

import { getAnthropicClient, isFakeMode, LIGHT_MODEL } from "../ai/client";
import { mergeFlags, ruleFlags } from "./flags";
import { supportsEffort } from "./models";
import type { Flag, FlagLevel, ParsedCase } from "./types";

export interface ParseResult {
  chips: ParsedCase;
  flags: Flag[];
  /** true when the model call failed and the keyword fallback was used. */
  degraded: boolean;
}

export type ParseCaller = (input: string) => Promise<{
  chips: ParsedCase;
  flags: Array<{ level: FlagLevel; text: string }>;
}>;

const PARSE_TIMEOUT_MS = 8_000;
const MAX_CHIPS = 8;
const MAX_CHIP_CHARS = 40;

const PROCEDURE_HINT =
  /필러|보톡스|톡신|보툴|리프팅|토닝|레이저|부스터|쥬베룩|리쥬란|울쎄라|슈링크|써마지|인모드|올리지오|피코|ipl|co2|프락셀|스킨|주사|시술|제모|박피|필링|엘란쎄|스컬트라/i;
const MED_HINT =
  /복용|약$|mg|캡슐|아스피린|와파린|이소트레티노인|로아큐탄|피임|스테로이드|항생제|aspirin|warfarin|isotretinoin/i;
const PATIENT_HINT =
  /\d+\s*대|\d+\s*세|남성|여성|^남$|^여$|남자|여자|피부\s*타입|fitzpatrick|지성|건성|민감성|흡연|임신|수유/i;

/** Drops Korean mobile numbers and resident registration numbers before
 * the memo goes anywhere, and bounds its length. */
export function sanitizeInput(input: string): string {
  return input
    .replace(/01[016789][-\s.]?\d{3,4}[-\s.]?\d{4}/g, "")
    .replace(/\d{6}[-\s]?[1-4]\d{6}/g, "")
    .slice(0, 500)
    .trim();
}

function normalize(items: string[]): string[] {
  const seen = new Set<string>();
  const out: string[] = [];
  for (const raw of items) {
    const item = raw.trim().slice(0, MAX_CHIP_CHARS);
    if (!item || seen.has(item)) continue;
    seen.add(item);
    out.push(item);
  }
  return out.slice(0, MAX_CHIPS);
}

export function normalizeChips(chips: ParsedCase): ParsedCase {
  return {
    patient: normalize(chips.patient),
    conditions: normalize(chips.conditions),
    meds: normalize(chips.meds),
    procedures: normalize(chips.procedures),
  };
}

export function fallbackParse(input: string): ParsedCase {
  const chips: ParsedCase = { patient: [], conditions: [], meds: [], procedures: [] };
  const parts = sanitizeInput(input)
    .split(/[,，、/·\n]+/)
    .map((part) => part.trim())
    .filter(Boolean);
  for (const part of parts) {
    if (PROCEDURE_HINT.test(part)) chips.procedures.push(part.replace(/\s*희망$/, ""));
    else if (MED_HINT.test(part)) chips.meds.push(part.replace(/\s*복용(\s*중)?$/, ""));
    else if (PATIENT_HINT.test(part)) chips.patient.push(part);
    else chips.conditions.push(part);
  }
  return normalizeChips(chips);
}

const PARSE_SCHEMA: { [key: string]: unknown } = {
  type: "object",
  properties: {
    patient: { type: "array", items: { type: "string" } },
    conditions: { type: "array", items: { type: "string" } },
    meds: { type: "array", items: { type: "string" } },
    procedures: { type: "array", items: { type: "string" } },
    flags: {
      type: "array",
      items: {
        type: "object",
        properties: {
          level: { type: "string", enum: ["contraindication", "caution"] },
          text: { type: "string" },
        },
        required: ["level", "text"],
        additionalProperties: false,
      },
    },
  },
  required: ["patient", "conditions", "meds", "procedures", "flags"],
  additionalProperties: false,
};

export function buildParsePrompt(input: string): string {
  return `미용의학 진료 중 의사가 입력한 한 줄 메모를 구조화하세요.

- patient: 나이대·성별·피부타입·생활습관 등 환자 특징 (짧은 명사구)
- conditions: 주소·질환·피부 고민·기저질환
- meds: 복용 중인 약 (약 이름만)
- procedures: 희망하거나 계획된 시술 (시술명만)
- flags: 이 조합에서 시술 전에 반드시 짚어야 할 금기(contraindication) 또는 주의(caution). 근거가 분명한 것만, 각 한 줄. 없으면 빈 배열.

이름·연락처·주민번호 같은 식별정보는 어떤 필드에도 넣지 마세요. 메모에 없는 사실을 추가하지 마세요.

<memo>
${input}
</memo>`;
}

export const anthropicParseCaller: ParseCaller = async (input) => {
  const response = await getAnthropicClient().messages.create({
    model: LIGHT_MODEL,
    max_tokens: 2000,
    output_config: {
      ...(supportsEffort(LIGHT_MODEL) ? { effort: "low" as const } : {}),
      format: { type: "json_schema", schema: PARSE_SCHEMA },
    },
    messages: [{ role: "user", content: buildParsePrompt(input) }],
  });
  if (response.stop_reason === "refusal") throw new Error("parse refused");
  const block = response.content.find((b) => b.type === "text");
  if (!block || block.type !== "text") throw new Error("parse returned no text");
  const { flags, ...chips } = JSON.parse(block.text) as ParsedCase & {
    flags: Array<{ level: FlagLevel; text: string }>;
  };
  return { chips, flags };
};

export const fakeParseCaller: ParseCaller = async (input) => ({
  chips: fallbackParse(input),
  flags: [],
});

function withTimeout<T>(promise: Promise<T>, ms: number): Promise<T> {
  let timer: ReturnType<typeof setTimeout> | undefined;
  const timeout = new Promise<never>((_, reject) => {
    timer = setTimeout(() => reject(new Error("parse timeout")), ms);
  });
  return Promise.race([promise, timeout]).finally(() => clearTimeout(timer));
}

export async function parseCase(input: string, caller?: ParseCaller): Promise<ParseResult> {
  const clean = sanitizeInput(input);
  const call = caller ?? (isFakeMode() ? fakeParseCaller : anthropicParseCaller);
  try {
    const result = await withTimeout(call(clean), PARSE_TIMEOUT_MS);
    const chips = normalizeChips(result.chips);
    const modelFlags: Flag[] = result.flags.map((f) => ({ ...f, source: "model" }));
    return { chips, flags: mergeFlags(ruleFlags(chips, clean), modelFlags), degraded: false };
  } catch {
    const chips = fallbackParse(clean);
    return { chips, flags: mergeFlags(ruleFlags(chips, clean), []), degraded: true };
  }
}

/** Static — no per-request text, so it caches across every BBIP call. */
export function buildBbipSystemPrompt(): string {
  return `당신은 "BBIP", 한국 미용 GP(일반의) 원장의 진료 비서입니다. 원장이 상담·시술 중에 환자 케이스를 보고 묻습니다. 바쁜 진료 중에 읽으므로 짧고, 훑어보기 쉽고, 정확해야 합니다.

1. 근거는 원장의 노트(<notes>)가 1순위입니다. 노트에서 온 내용은 문장 끝에 [n]으로 인용합니다 (여러 개면 [1][3]).

5. 노트끼리 내용이 다르면 한쪽을 고르지 말고 "> ⚠️ 충돌:" 블록으로 드러냅니다.
6. 모르는 것은 모른다고 씁니다. 지어내지 않습니다.
7. <flags>에 항목이 있으면 관련 내용을 가장 먼저 다룹니다.

- 서론·맺음말·면책 문구는 쓰지 않습니다.`;
}

export function buildCaseBlock(chips: ParsedCase, flags: Flag[]): string {
  const line = (label: string, items: string[]) =>
    `${label}: ${items.length ? items.join(", ") : "-"}`;
  const flagLines = flags.length
    ? flags.map((f) => `- [${f.level === "contraindication" ? "금기" : "주의"}] ${f.text}`).join("\n")
    : "- 없음";
  return [
    "<case>",
    line("환자 특징", chips.patient),
    line("질환·고민", chips.conditions),
    line("복용약", chips.meds),
    line("시술", chips.procedures),
    "</case>",
    "",
    "<flags>",
    flagLines,
    "</flags>",
  ].join("\n");
}

export interface PromptNote {
  n: number;
  entry: CodexEntry;
  verified: boolean;
}

export function isUnverifiedBbipNote(entry: CodexEntry): boolean {
  return (
    entry.status === "draft" &&
    entry.sources.some((source) => source.citation.startsWith(BBIP_SOURCE_PREFIX))
  );
}

function attr(value: string): string {
  return value.replace(/"/g, "'");
}

export function buildNotesBlock(notes: PromptNote[]): string {
  if (notes.length === 0) {
    return "<notes>\n(관련 노트 없음 — 모든 내용은 [AI]로 표시)\n</notes>";
  }
  const blocks = notes.map(({ n, entry, verified }) => {
    const body = entry.content.trim();
    const excerpt =
      body.length <= NOTE_EXCERPT_CHARS ? body : `${body.slice(0, NOTE_EXCERPT_CHARS)}\n…(생략)`;
    return `<note n="${n}" title="${attr(entry.title)}" verified="${verified}">\n${excerpt}\n</note>`;
  });
  return `<notes>\n${blocks.join("\n\n")}\n</notes>`;
}

/** Earlier cards as bounded context: the brief in full, other cards by
 * their first paragraph. Failed/streaming turns are skipped. */
export function buildPriorTurnsBlock(turns: BbipTurn[]): string {
  const parts = turns
    .filter((turn) => turn.status === "done" && turn.output.trim())
    .map((turn) => {
      const body =
        turn.kind === "brief"
          ? turn.output.trim()
          : (turn.output.trim().split(/\n\s*\n/)[0] ?? "");
      return `[${turnTitle(turn)}]\n${body}`;
    });
  if (parts.length === 0) return "";
  let text = parts.join("\n\n");
  if (text.length > PRIOR_LIMIT) text = `${text.slice(0, PRIOR_LIMIT)}\n…(생략)`;
  return `<previous>\n${text}\n</previous>`;
}

const BRIEF_INSTRUCTION = `## 요청: 핵심 브리핑
이 케이스에서 원장이 지금 알아야 할 것만 5~7개 불릿으로 쓰세요. 순서: 금기·주의 → 핵심 시술팁 → 주요 리스크 → 권장 회차 → 한 줄 업셀.
각 불릿은 한 줄, 끝에 근거 표시([n] 또는 [AI]). 소제목·서론 없이 불릿만.

불릿 다음 줄에, 원장이 이어서 물어볼 만한 이 케이스 맞춤 후속 질문 3~4개를 아래 형식 그대로 붙이세요 (각 30자 이내):
<followups>["질문1","질문2","질문3"]</followups>`;

export function buildTurnInstruction(request: TurnRequest): string {

import type Anthropic from "@anthropic-ai/sdk";
import type { CodexEntry } from "../codex/types";
import { getCategory } from "../codex/taxonomy";
import {
  buildBbipSystemPrompt,
  buildCaseBlock,
  buildNotesBlock,
  buildPriorTurnsBlock,
  buildTurnInstruction,
  isUnverifiedBbipNote,
  type PromptNote,
} from "./prompts";
import type { BbipSession, BbipTurn, NoteRef, TurnRequest } from "./types";

export interface TurnContext {
  system: Anthropic.Beta.BetaTextBlockParam[];
  messages: Anthropic.Beta.BetaMessageParam[];
  noteRefs: NoteRef[];
}

/** Session notes in citation order. A note deleted since the session was
 * created is skipped but the others keep their original [n]. */
export function selectPromptNotes(session: BbipSession, entries: CodexEntry[]): PromptNote[] {
  const byId = new Map(entries.map((e) => [e.id, e]));
  const notes: PromptNote[] = [];
  session.sourceNoteIds.forEach((id, index) => {
    const entry = byId.get(id);
    if (entry) notes.push({ n: index + 1, entry, verified: !isUnverifiedBbipNote(entry) });
  });
  return notes;
}

function categoryLabel(key: string): string {
  try {
    return getCategory(key).labelKo;
  } catch {
    return key;
  }
}

export function noteRefsFor(notes: PromptNote[]): NoteRef[] {
  return notes.map(({ n, entry }) => ({
    n,
    id: entry.id,
    title: entry.title,
    categoryLabel: categoryLabel(entry.categoryKey),
  }));
}

/** Prompt layout, most-stable first:
 *  ① system (static)                         — cache breakpoint
 *  ② case + flags + session notes (per session) — cache breakpoint
 *  ③ previous cards + this turn's instruction (volatile) */
export function buildTurnContext(args: {
  session: BbipSession;
  entries: CodexEntry[];
  priorTurns: BbipTurn[];
  request: TurnRequest;
}): TurnContext {
  const notes = selectPromptNotes(args.session, args.entries);
  const stable = `${buildCaseBlock(args.session.chips, args.session.flags)}\n\n${buildNotesBlock(notes)}`;
  const volatile = [buildPriorTurnsBlock(args.priorTurns), buildTurnInstruction(args.request)]
    .filter(Boolean)
    .join("\n\n");
  return {
    system: [{ type: "text", text: buildBbipSystemPrompt(), cache_control: { type: "ephemeral" } }],
    messages: [
      {
        role: "user",
        content: [
          { type: "text", text: stable, cache_control: { type: "ephemeral" } },
          { type: "text", text: volatile },
        ],
      },
    ],
    noteRefs: noteRefsFor(notes),
  };
}

    }

import { isFakeMode } from "../ai/client";
import type { CodexEntry } from "../codex/types";
import { listEntries } from "../services/entryService";
import {
  failTurn,
  finishTurn,
  getSession,
  listTurns,
  startTurn,
} from "../services/bbipService";
import { FollowupExtractor } from "./followups";
import { generateTurnText, type GenerateArgs } from "./generate";
import { modelForRequest } from "./models";
import type { StreamEvent, TurnRequest } from "./types";

export interface RunTurnDeps {
  listEntries: () => Promise<CodexEntry[]>;
  generate: (args: GenerateArgs) => AsyncIterable<string>;
}

const defaultDeps: RunTurnDeps = { listEntries: () => listEntries(), generate: generateTurnText };

/** Generates one card and persists it as it goes. The turn row is written
 * as "streaming" first and closed as "done"/"failed", so a client that
 * disconnects can still find the finished card in history. */
export async function* runTurn(
  sessionId: string,
  request: TurnRequest,
  deps: RunTurnDeps = defaultDeps
): AsyncGenerator<StreamEvent> {
  const session = getSession(sessionId);
  if (!session) {
    yield { type: "error", message: "세션을 찾을 수 없습니다." };
    return;
  }
  const wanted = new Set(session.sourceNoteIds);
  const entries = (await deps.listEntries()).filter((e) => wanted.has(e.id));
  const priorTurns = listTurns(sessionId).filter((t) => t.status === "done");
  const model = isFakeMode() ? "fake" : modelForRequest(request).model;
  const turn = startTurn(sessionId, request, model);
  yield { type: "start", turnId: turn.id };

  const extractor = request.kind === "brief" ? new FollowupExtractor() : null;
  let output = "";
  try {
    for await (const chunk of deps.generate({ session, entries, priorTurns, request })) {
      const visible = extractor ? extractor.push(chunk) : chunk;
      if (visible) {
        output += visible;
        yield { type: "delta", text: visible };
      }
    }
    const finished = extractor?.finish() ?? { tail: "", followups: [] };
    if (finished.tail) {
      output += finished.tail;
      yield { type: "delta", text: finished.tail };
    }
    finishTurn(turn.id, output.trimEnd(), finished.followups);
    if (finished.followups.length) yield { type: "followups", items: finished.followups };
    yield { type: "done", turnId: turn.id };
  } catch (error) {
    const message = error instanceof Error ? error.message : "알 수 없는 오류";
    failTurn(turn.id, output, message);
    yield { type: "error", message: `생성 실패: ${message}` };
  }
}

// lib/bbip/ndjson.ts
import type { StreamEvent } from "./types";

/** Push-style stream: the generator is drained in start(), so a turn keeps
 * generating and saving even after the client disconnects. */
export function ndjsonStream(events: AsyncIterable<StreamEvent>): ReadableStream<Uint8Array> {
  const encoder = new TextEncoder();
  return new ReadableStream<Uint8Array>({
    async start(controller) {
      let open = true;
      for await (const event of events) {
        if (!open) continue;
        try {
          controller.enqueue(encoder.encode(`${JSON.stringify(event)}\n`));
        } catch {
          open = false;
        }
      }
      if (open) {
        try {
          controller.close();
        } catch {
          /* consumer already cancelled */
        }
      }
    },
  });
}
```

// lib/bbip/readNdjson.ts
import type { StreamEvent } from "./types";

export async function* readNdjson(body: ReadableStream<Uint8Array>): AsyncGenerator<StreamEvent> {
  const reader = body.getReader();
  const decoder = new TextDecoder();
  let buffer = "";
  for (;;) {
    const { done, value } = await reader.read();
    if (done) break;
    buffer += decoder.decode(value, { stream: true });
    let newline = buffer.indexOf("\n");
    while (newline >= 0) {
      const line = buffer.slice(0, newline).trim();
      buffer = buffer.slice(newline + 1);
      if (line) yield JSON.parse(line) as StreamEvent;
      newline = buffer.indexOf("\n");
    }
  }
  const rest = (buffer + decoder.decode()).trim();
  if (rest) yield JSON.parse(rest) as StreamEvent;
}

import { normalizeChips, parseCase, type ParseResult } from "./parse";
import type { CreateSessionBody } from "./schemas";
import type { BbipSession, NoteRef, ParsedCase, SessionView } from "./types";

export const RETRIEVE_LIMIT = 12;

export function chipQuery(chips: ParsedCase): string {
  return [...chips.procedures, ...chips.conditions, ...chips.meds, ...chips.patient].join(" ");
}

export interface OpenSessionDeps {
  listEntries: () => Promise<CodexEntry[]>;
  parse: (input: string) => Promise<ParseResult>;
}

const defaultDeps: OpenSessionDeps = {
  listEntries: () => listEntries(),
  parse: (input) => parseCase(input),
};

/** Parse (or take edited chips), retrieve once, persist. Retrieval is fixed
 * for the session so every turn shares the same cached prompt prefix. */
export async function openSession(
  body: CreateSessionBody,
  deps: OpenSessionDeps = defaultDeps
): Promise<{ session: BbipSession; notes: NoteRef[]; degraded: boolean }> {
  let parsed: ParseResult;
  if ("chips" in body) {
    // Edited chips skip the parser, so scrub them the same way (PII, caps).
    const chips = normalizeChips(body.chips);
    parsed = { chips, flags: mergeFlags(ruleFlags(chips), []), degraded: false };
  } else {
    parsed = await deps.parse(body.input);
  }
  const entries = await deps.listEntries();
  const retrieved = retrieve(chipQuery(parsed.chips), entries, RETRIEVE_LIMIT).map((r) => r.note);
  const session = createSession({
    chips: parsed.chips,
    flags: parsed.flags,
    sourceNoteIds: retrieved.map((note) => note.id),
  });
  return {
    session,
    notes: noteRefsFor(selectPromptNotes(session, retrieved)),
    degraded: parsed.degraded,
  };
}

export async function loadSessionView(id: string): Promise<SessionView | null> {
  const session = getSession(id);
  if (!session) return null;
  // A crash/restart mid-generation leaves turns "streaming" forever; close them.
  failStaleTurns();
  const entries = await listEntries();
  return {
    session,
    turns: listTurns(id),
    notes: noteRefsFor(selectPromptNotes(session, entries)),
  };
}

import { buildPromoteInput, promoteDefaults } from "../../../../../../lib/bbip/promote";
import { promoteSchema } from "../../../../../../lib/bbip/schemas";
import { getSession, getTurn, markPromoted } from "../../../../../../lib/services/bbipService";
import { createEntry, deleteEntry, listEntries } from "../../../../../../lib/services/entryService";

export const dynamic = "force-dynamic";

type Params = { params: Promise<{ turnId: string }> };

async function load(turnId: string) {
  const turn = getTurn(turnId);
  const session = turn ? getSession(turn.sessionId) : null;
  if (!turn || !session) return null;
  const notes = selectPromptNotes(session, await listEntries());
  return { turn, session, notes };
}

/** GET → PromoteDefaults for the dialog. */
export async function GET(_request: Request, { params }: Params) {
  const { turnId } = await params;
  const loaded = await load(turnId);
  if (!loaded) return Response.json({ error: "카드를 찾을 수 없습니다." }, { status: 404 });
  return Response.json(promoteDefaults(loaded.session, loaded.turn, loaded.notes));
}

/** POST { title, categoryKey, tier, selection? } → { entryId } */
export async function POST(request: Request, { params }: Params) {
  const { turnId } = await params;
  const body = await request.json().catch(() => null);
  const parsed = promoteSchema.safeParse(body);
  if (!parsed.success) {
    return Response.json(
      { error: parsed.error.issues[0]?.message ?? "입력값을 확인해 주세요." },
      { status: 400 }
    );
  }
  const loaded = await load(turnId);
  if (!loaded) return Response.json({ error: "카드를 찾을 수 없습니다." }, { status: 404 });
  if (loaded.turn.status !== "done") {
    return Response.json({ error: "완성된 카드만 저장할 수 있습니다." }, { status: 409 });
  }
  if (loaded.turn.promotedEntryId) {
    return Response.json(
      { error: "이미 노트로 저장된 카드입니다.", entryId: loaded.turn.promotedEntryId },
      { status: 409 }
    );
  }
  try {
    const input = buildPromoteInput({
      session: loaded.session,
      turn: loaded.turn,
      notes: noteRefsFor(loaded.notes),
      ...parsed.data,
    });
    const { entry } = await createEntry(input);
    // markPromoted only claims an unclaimed turn; a concurrent double-submit
    // loses here and its freshly created duplicate note is rolled back.
    if (!markPromoted(turnId, entry.id)) {
      await deleteEntry(entry.id);
      const winner = getTurn(turnId)?.promotedEntryId;
      return Response.json(
        { error: "이미 노트로 저장된 카드입니다.", entryId: winner },
        { status: 409 }
      );
    }
    return Response.json({ entryId: entry.id });
  } catch (error) {
    return Response.json(
      { error: error instanceof Error ? error.message : "노트 저장에 실패했습니다." },
      { status: 400 }
    );
  }
}

import type {
  BbipSession,
  BbipTurn,
  NoteRef,
  SectionKey,
  SessionView,
  StreamEvent,
  TurnKind,
  TurnRequest,
  TurnStatus,
} from "./types";

export interface ClientTurn {
  /** Stable React key; equals the server id for hydrated turns. */
  key: string;
  id?: string;
  kind: TurnKind;
  sectionKey?: SectionKey;
  question?: string;
  output: string;
  followups: string[];
  status: TurnStatus;
  error?: string;
  promotedEntryId?: string;
}

export interface ConsoleState {
  session: BbipSession | null;
  notes: NoteRef[];
  turns: ClientTurn[];
  degraded: boolean;
}

export type ConsoleAction =
  | { type: "reset"; view: SessionView; degraded: boolean }
  | { type: "turn-start"; key: string; request: TurnRequest }
  | { type: "turn-event"; key: string; event: StreamEvent }
  | { type: "turn-remove"; key: string }
  | { type: "promoted"; turnId: string; entryId: string }
  /** Server snapshot for turns hydrated while still streaming (page reload
   * mid-generation): replaces those cards once the server has moved on. */
  | { type: "sync"; turns: BbipTurn[] };

function fromServer(turn: BbipTurn): ClientTurn {
  return {
    key: turn.id,
    id: turn.id,
    kind: turn.kind,
    sectionKey: turn.sectionKey,
    question: turn.question,
    output: turn.output,
    followups: turn.followups,
    status: turn.status,
    error: turn.error,
    promotedEntryId: turn.promotedEntryId,
  };
}

export function initialConsoleState(view: SessionView | null): ConsoleState {
  if (!view) return { session: null, notes: [], turns: [], degraded: false };
  return { session: view.session, notes: view.notes, turns: view.turns.map(fromServer), degraded: false };
}

export function requestOf(turn: ClientTurn): TurnRequest {
  return { kind: turn.kind, sectionKey: turn.sectionKey, question: turn.question };
}

function applyEvent(turn: ClientTurn, event: StreamEvent): ClientTurn {
  switch (event.type) {
    case "start":
      return { ...turn, id: event.turnId };
    case "delta":
      return { ...turn, output: turn.output + event.text };
    case "followups":
      return { ...turn, followups: event.items };
    case "done":
      return { ...turn, id: event.turnId, status: "done" };
    case "error":
      return { ...turn, status: "failed", error: event.message };
  }
}

export function consoleReducer(state: ConsoleState, action: ConsoleAction): ConsoleState {
  switch (action.type) {
    case "reset":
      return { ...initialConsoleState(action.view), degraded: action.degraded };
    case "turn-start":
      return {
        ...state,
        turns: [
          ...state.turns,
          {
            key: action.key,
            kind: action.request.kind,
            sectionKey: action.request.sectionKey,
            question: action.request.question,
            output: "",
            followups: [],
            status: "streaming",
          },
        ],
      };
    case "turn-event":
      return {
        ...state,
        turns: state.turns.map((t) => (t.key === action.key ? applyEvent(t, action.event) : t)),
      };
    case "turn-remove":
      return { ...state, turns: state.turns.filter((t) => t.key !== action.key) };
    case "promoted":
      return {
        ...state,
        turns: state.turns.map((t) =>
          t.id === action.turnId ? { ...t, promotedEntryId: action.entryId } : t
        ),
      };
    case "sync": {
      const byId = new Map(action.turns.map((t) => [t.id, t]));
      return {
        ...state,
        turns: state.turns.map((t) => {
          const server = t.id ? byId.get(t.id) : undefined;
          return server && t.key === t.id && t.status === "streaming" ? fromServer(server) : t;
        }),
      };
    }
  }
}

/** Hydrated cards still streaming on the server (not driven by this tab). */
export function hasDetachedStreaming(state: ConsoleState): boolean {
  return state.turns.some((t) => t.status === "streaming" && t.key === t.id);
}

"use client";

import { useCallback, useEffect, useReducer, useRef, useState } from "react";
import type { CategoryDef } from "../../lib/codex/types";
import {
  consoleReducer,
  hasDetachedStreaming,
  initialConsoleState,
  requestOf,
  type ClientTurn,
} from "../../lib/bbip/consoleState";
import { readNdjson } from "../../lib/bbip/readNdjson";
import type { ParsedCase, SectionKey, SessionView, TurnRequest } from "../../lib/bbip/types";
import { CaseInput } from "./CaseInput";
import { ChipBar } from "./ChipBar";
import { FlagBanner } from "./FlagBanner";
import { HistoryDrawer } from "./HistoryDrawer";
import { MoreMenu } from "./MoreMenu";
import { PromoteDialog } from "./PromoteDialog";
import { TurnCard } from "./TurnCard";

export function BbipConsole({
  initialView,
  leafCategories,
}: {
  initialView: SessionView | null;
  leafCategories: CategoryDef[];
}) {
  const [state, dispatch] = useReducer(consoleReducer, initialView, initialConsoleState);
  const [opening, setOpening] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const [promoteTurnId, setPromoteTurnId] = useState<string | null>(null);
  const keySeq = useRef(0);

  const runTurn = useCallback(async (sessionId: string, request: TurnRequest) => {
    const key = `local-${++keySeq.current}`;
    dispatch({ type: "turn-start", key, request });
    try {
      const res = await fetch(`/api/bbip/sessions/${sessionId}/turns`, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify(request),
      });
      if (!res.ok || !res.body) {
        const data = await res.json().catch(() => ({}));
        dispatch({
          type: "turn-event",
          key,
          event: { type: "error", message: data.error ?? "생성 요청에 실패했습니다." },
        });
        return;
      }
      let terminal = false;
      for await (const event of readNdjson(res.body)) {
        if (event.type === "done" || event.type === "error") terminal = true;
        dispatch({ type: "turn-event", key, event });
      }
      if (!terminal) {
        dispatch({ type: "turn-event", key, event: { type: "error", message: "연결이 끊겼습니다." } });
      }
    } catch {
      dispatch({ type: "turn-event", key, event: { type: "error", message: "네트워크 오류" } });
    }
  }, []);

  // Reloaded mid-generation: the server keeps streaming into the DB, so poll
  // the session until those cards settle.
  const detached = hasDetachedStreaming(state);
  const sessionId = state.session?.id;
  useEffect(() => {
    if (!detached || !sessionId) return;
    const timer = setInterval(async () => {
      try {
        const res = await fetch(`/api/bbip/sessions/${sessionId}`);
        if (res.ok) dispatch({ type: "sync", turns: (await res.json()).turns });
      } catch {
        /* next tick retries */
      }
    }, 2000);
    return () => clearInterval(timer);
  }, [detached, sessionId]);

  async function openSession(body: { input: string } | { chips: ParsedCase }) {
    setOpening(true);
    setError(null);
    try {
      const res = await fetch("/api/bbip/sessions", {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify(body),
      });
      const data = await res.json();
      if (!res.ok) {
        setError(data.error ?? "케이스를 열지 못했습니다.");
        return;
      }
      dispatch({
        type: "reset",
        view: { session: data.session, turns: [], notes: data.notes },
        degraded: data.degraded,
      });
      // Shareable URL without a server round trip (keeps this component mounted).
      window.history.replaceState(null, "", `/?s=${data.session.id}`);
      void runTurn(data.session.id, { kind: "brief" });
    } catch {
      setError("네트워크 오류로 케이스를 열지 못했습니다.");
    } finally {
      setOpening(false);
    }
  }

  function retry(turn: ClientTurn) {
    if (!state.session) return;
    dispatch({ type: "turn-remove", key: turn.key });
    void runTurn(state.session.id, requestOf(turn));
  }

  const session = state.session;
  const brief = state.turns.find((t) => t.kind === "brief");
  const others = state.turns.filter((t) => t !== brief);
  const openedSections = new Set(
    state.turns.flatMap((t) => (t.kind === "section" && t.sectionKey ? [t.sectionKey] : []))
  ) as Set<SectionKey>;

  return (
    <div className="flex gap-6">
      <HistoryDrawer activeId={session?.id ?? null} />
      <div className="min-w-0 flex-1">
        <div className="mb-2 flex items-center gap-3 font-mono text-[10px] tracking-[0.2em] md:text-[11px]">
          <span className="text-ink/60">[ BBIP ]</span>
          <span className="font-bold uppercase text-ink">케이스를 넣으면 핵심부터</span>
        </div>
        <h1 className="mb-5 font-serifa text-2xl font-bold tracking-tight text-inkdeep md:text-3xl">
          미용 GP 진료 비서
        </h1>

        <CaseInput disabled={opening} onSubmit={(input) => void openSession({ input })} />
        {error && (
          <p role="alert" className="mt-3 text-sm text-red-700">
            {error}
          </p>
        )}

        {session && (
          <>
            <ChipBar
              chips={session.chips}
              disabled={opening}
              onChange={(chips) => void openSession({ chips })}
            />
            {state.degraded && (
              <p className="mt-2 text-xs text-amber-800">
                자동 분류에 실패해 단순 분리했습니다 — 칩을 확인하세요.
              </p>
            )}
            <FlagBanner flags={session.flags} />
            {state.notes.length === 0 && (
              <p className="mt-3 text-xs text-ink/60">
                내 노트에 관련 자료가 없습니다 — 아래 내용은 🤖AI 보충 위주입니다.
              </p>
            )}

            {brief && (
              <TurnCard turn={brief} notes={state.notes} onRetry={retry} onPromote={setPromoteTurnId} />
            )}
            {brief && brief.status !== "streaming" && (
              <MoreMenu
                followups={brief.followups}
                openedSections={openedSections}
                onRequest={(request) => void runTurn(session.id, request)}
              />
            )}
            {others.map((turn) => (
              <TurnCard
                key={turn.key}
                turn={turn}
                notes={state.notes}
                onRetry={retry}
                onPromote={setPromoteTurnId}
              />
            ))}
          </>
        )}
      </div>

      {promoteTurnId && (
        <PromoteDialog
          turnId={promoteTurnId}
          leafCategories={leafCategories}
          onClose={() => setPromoteTurnId(null)}
          onSaved={(entryId) => {
            dispatch({ type: "promoted", turnId: promoteTurnId, entryId });
            setPromoteTurnId(null);
          }}
        />
      )}
    </div>
  );
}
